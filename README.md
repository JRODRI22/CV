# Jorge Rodríguez — Portfolio & CV

Portfolio personal y CV interactivo de **Jorge Rodríguez**, Backend Developer con 5+ años en .NET, SQL Server y sistemas empresariales.

## Stack

- React 19 + Vite 6
- TailwindCSS 4
- Framer Motion 12
- Three.js / React Three Fiber

## Páginas

| Ruta | Descripción |
|------|-------------|
| `/` | Portfolio — JR Digital Solutions |
| `/cv` | CV interactivo con diseño dark |

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
# dist/index.html  → Portfolio
# dist/cv.html     → CV standalone
```
